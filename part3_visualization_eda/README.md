# Part 3 — Visualization, EDA & Business Thinking

## Project Overview

This project analyzes YouTube trending video statistics
from the US, GB, and IN datasets.

The goal is to understand category popularity, video
engagement, trending retention, and country differences.

## Dataset Source

Trending YouTube Video Statistics dataset.

The country CSV files and categories.csv are committed
inside the data/ folder.
